# 网络与 VPN 排查 / Network and VPN

VPN 无法连接时先确认普通网页能否访问，再检查企业 VPN 客户端版本和登录状态。记录错误码与出现时间，重连一次；持续失败交给 IT。If VPN cannot connect, first check ordinary internet access, then the approved VPN client version and sign-in state. Record the error code and time, reconnect once and contact IT if it persists.

办公 Wi-Fi 掉线时确认连接的是批准的网络，比较附近同事是否同样受影响。不要绕过认证或更改公司防火墙规则。For office Wi-Fi drops, check the approved network and whether nearby coworkers are affected. Do not bypass authentication or change company firewall rules.

多人无法联网应登记楼层、网络名称、开始时间和影响人数，按团队故障处理。若全公司核心服务中断则按高优先级事故处理。For network problems affecting several people, capture location, network, onset and scope. A company-wide core-service outage requires urgent incident response.
