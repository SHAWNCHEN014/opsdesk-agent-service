# 软件与应用支持 / Software and application support

安装软件前须说明软件名称、用途、许可需求和主管批准。只使用公司批准的软件目录，IT 检查授权与兼容性后部署。Installation requests need the software, purpose, licence requirement and manager approval. Use the approved catalogue; IT verifies licensing and compatibility before deployment.

应用报错时记录版本、去除敏感信息的错误提示、操作步骤和发生时间。先保存工作，再按该应用批准的恢复步骤重启；不执行未知脚本。For application errors, capture version, redacted error, steps and time. Save your work before an approved restart. Never execute unknown scripts.

申请新软件不等于已获授权。不要将审批、安装或恢复状态写成已完成，实际状态以 IT 工单为准。A request is not an approval. Approval, installation and recovery remain pending until confirmed in the work order.
